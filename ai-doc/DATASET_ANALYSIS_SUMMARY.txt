PREPROCESSING RECOMMENDATIONS
------------------------------
1. Normalization: Scale to [0, 1] or [-1, 1]
   - Method 1: image / 255.0
   - Method 2: (image - mean) / std
   - Dataset mean: 54.73, std: 47.85

2. Data Augmentation:
   - Horizontal flip (50% probability)
   - Random rotation (±10 degrees)
   - Random crop/zoom (0.8-1.0 scale)
   - Speckle noise (OCT-specific)
   - Brightness/contrast adjustment

3. Class Balancing:
   - Use WeightedRandomSampler
   - Or oversample DRUSEN (7.96%) and DME (10.48%)

PATIENT-LEVEL CONSIDERATIONS
-----------------------------
⚠️ IMPORTANT: Multiple B-scans per patient exist
  - Extract PATIENT_ID from filename
  - Use patient-level train/val split to prevent data leakage
  - Avoid having same patient in both train and validation

Recommended split strategy:
  1. Extract unique patient IDs
  2. Split patients (not images) into train/val
  3. Assign all images from each patient to respective split

   - Learn compressed latent representation

2. Diffusion Model (Stage 2):
